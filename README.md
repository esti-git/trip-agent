# 🗺️ Trip Agent: סוכן לתכנון טיול יומי

אג'נט שמתכנן טיול יומי בישראל שמתאים למזג האוויר, לזמן הנסיעה ולשעות האור.

## הבעיה ומה האג'נט עושה

**הבעיה:** כדי לתכנן יציאה ליום חופש צריך לבדוק כמה דברים שתלויים זה בזה: מה מזג האוויר, איזה טיול מתאים לו (ביום גשום מקום מקורה, בשרב מים וצל), אילו מקומות קרובים מספיק, והאם מספיקים לחזור לפני החשכה. בדרך כלל עושים את זה בכמה אתרים שונים, וקל לפספס משהו.

**למה דווקא אג'נט:** אי אפשר לפתור את זה בשאלה אחת. כל צעד תלוי בתוצאה של הצעד הקודם, ולכן צריך מישהו שמחליט בעצמו מה לבדוק הלאה, ולא תוכנית שמבצעת רשימת פקודות קבועה.

**מה האג'נט עושה:** מקבל עיר מוצא, תאריך, זמן נסיעה מקסימלי ואם רוצים גם סוג טיול. הוא בודק את התחזית ומחליט איזה טיול מתאים. אם ביקשו סוג שלא מתאים למזג האוויר, הוא מציע חלופה ומסביר למה. אחר כך הוא מציע מקום, מאמת אותו על המפה, בודק זמן נסיעה ובונה לוח זמנים שמסתיים לפני השקיעה. כשמשהו לא מסתדר (המקום לא נמצא, רחוק מדי, או לא מספיקים עד השקיעה), הוא מנסה מקום אחר. אם אין אפשרות טובה, הוא עוצר ומסביר.

## הוראות הפעלה

**דרישות:** Python 3.10 ומעלה, ומפתח API של OpenAI. ריצה עולה פחות מסנט.

```bash
git clone https://github.com/esti-git/trip-agent.git
cd trip-agent
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```
(ב-Mac או ב-Linux: `.venv/bin/python` במקום `.venv\Scripts\python`)

**מפתח:** מעתיקים את `.env.example` לקובץ בשם `.env`, ומדביקים בו מפתח מ-[OpenAI](https://platform.openai.com/api-keys):
```
LLM_API_KEY=sk-...
```

**הרצה בממשק בדפדפן** (הצעדים מופיעים בזמן אמת):
```bash
.venv\Scripts\python -m streamlit run app.py
```

**או בטרמינל:**
```bash
.venv\Scripts\python main.py
```

**בדיקות** (בלי אינטרנט ובלי מפתח):
```bash
.venv\Scripts\python -m pytest
```

## איך האג'נט עובד

| מרכיב | איך הוא ממומש |
|---|---|
| **קבלת מטרה** | הקלט של המשתמש הופך להודעת מטרה ל-LLM |
| **קבלת החלטות** | ה-LLM בוחר בכל צעד איזה כלי להפעיל. בקוד אין סדר צעדים קבוע ואין `if` על מזג האוויר |
| **כלים** | `geocode` (מקום ← מיקום, OpenStreetMap), `get_weather` (תחזית ושקיעה, Open-Meteo), `travel_time` (זמן נסיעה משוער), `plan_schedule` (לוח זמנים מול השקיעה) |
| **בחינת התוצאה** | כל תוצאה, כולל שגיאות, חוזרת ל-LLM: רחוק מדי? מחפש קרוב יותר. לא מספיקים? מקצר את הביקור. לא נמצא? מנסה שם אחר |
| **תנאי סיום** | תוכנית מאומתת (📍), הסבר למה אין (❌), או עצירה אחרי 15 צעדים |

## אופן החשיבה: מה ה-LLM מחליט ומה הקוד מבטיח

**ה-LLM מחליט** איזה טיול מתאים, האם לכבד את הבקשה או להציע חלופה, אילו מקומות לבדוק ובאיזה סדר, מתי לצאת, ומה לעשות כשמשהו נכשל.

**הקוד מבטיח** את מה שחייב להיות נכון תמיד. כל אחת מהבדיקות האלה נוספה אחרי שראיתי בריצות שהמודל לא מציית רק להנחיות:
- **עיר המוצא היא עובדה, לא החלטה.** היא נבדקת לפני שהאג'נט מתחיל, וחייבת להיות יישוב. כשעיר לא נמצאה, ה-LLM "החליט" שהיא ליד עיר אחרת.
- **זמן נסיעה ותחזית רק למקומות אמיתיים.** הכלים מקבלים רק קואורדינטות של עיר המוצא או כאלה ש-`geocode` החזיר. כש"פארק יקום" לא נמצא, ה-LLM המציא נקודה וקיבל 22 דקות נסיעה למקום שנמצא שעה משם.
- **אין שעת יציאה שכבר עברה**, ואין נקודה מחוץ לישראל (פעם נשלחה נקודה במצרים).
- **הצעד הראשון חייב להפעיל כלי**, ותשובה בלי כלי נחשבת לסופית רק אם יש בה תוכנית או הסבר. פעם האג'נט "סיים" אחרי 0 בדיקות, אחרי שכתב "אני בודק…" בלי לבדוק.

הבדיקות האלה לא מכתיבות ל-LLM מה לעשות. הן רק מבטיחות שהעובדות שהוא מחליט לפיהן נכונות. כשבדיקה נכשלת, הוא מקבל שגיאה ומחליט בעצמו איך להמשיך.

**החלטות נוספות:**
- **OpenAI עם `gpt-4o-mini`**, כמו שההוראות ממליצות. התחלתי עם Gemini החינמי, אבל המכסה שלו נגמרה כבר בפיתוח.
- **המקומות מגיעים מה-LLM ומאומתים מול המפה.** מאגר האטרקציות של OpenStreetMap (Overpass) לא החזיר תשובות בבדיקות.
- **זמן הנסיעה הוא הערכה:** קו אוויר × 1.3 ב-60 קמ"ש. שירות ניווט חינמי לא היה אמין, וההערכה מספיקה כדי לבחור בין יעדים.
- **"לפני השקיעה"** = עוזבים את המקום לפחות 30 דקות לפני השקיעה.
- **`truststore`** מאפשר ל-Python להתחבר מאחורי סינון כמו NetFree. במחשב רגיל הוא לא משנה כלום.

## טיפול בשגיאות

- **תקלה בכלי** (שירות לא ענה, מקום לא נמצא, קלט שגוי) חוזרת ל-LLM כהודעה, והוא מחליט מה לעשות. כלים אף פעם לא קורסים.
- **ה-LLM עמוס או מחזיר תשובה ריקה:** ניסיון חוזר ומעבר למודל גיבוי.
- **מפתח חסר או שגוי, אין חיבור, קלט שגוי מהמשתמש:** הודעה ברורה בעברית.
- **שגיאה לא צפויה לגמרי:** הודעה קצרה בעברית במקום traceback.
- **59 בדיקות אוטומטיות**, כולל תקלות מדומות, בלי אינטרנט ובלי LLM.
